# 🚀 Antigravity Event Talks AI

An AI-powered web application that helps users discover, explore, and interact with event talks through an intelligent conversational interface.

## 📌 Overview

Antigravity Event Talks AI is designed to make event information easier to access using Generative AI. Instead of manually browsing through event details, users can ask questions in natural language and receive relevant responses instantly.

This project demonstrates the use of modern AI technologies combined with a responsive web interface to create an intuitive user experience.

## ✨ Features

* 🤖 AI-powered conversational assistant
* 🎤 Event and talk information retrieval
* ⚡ Fast and responsive interface
* 📱 Mobile-friendly design
* 💬 Natural language interaction
* 🎯 Simple and intuitive user experience

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/bhavyaraibatra15-hash/antigravity-event-talks-app.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build the project

```bash
npm run build
```
